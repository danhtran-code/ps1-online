🎩 Cheat Engine (GameShark)

Thêm mã GameShark cho game PS1. Mỗi mã gồm 8 ký tự hex địa chỉ + giá trị, nhiều dòng nối bằng dấu + (ví dụ: 80128FB4+00C8). Mã bật sẽ tự áp dụng khi game chạy.

  • Chưa có mã nào. Mã được lưu trên trình duyệt của bạn, theo từng game.

Mẹo: bật/tắt mã rồi bấm Áp dụng mã để đổi ngay trong lúc chơi. Một số mã cần khởi động lại game mới tắt hẳn.

Hoặc dùng nút Cheat có sẵn trên thanh công cụ của trình giả lập để quản lý mã.

❓ Cách dùng

  1. Chuẩn bị file game: file ảnh đĩa PS1 của bạn (.iso, .bin + .cue, .pbp, .chd…), có thể nén trong .zip.
  2. Nạp game ở trên rồi bấm Bắt đầu chơi. Game chạy hoàn toàn trên máy bạn bằng EmulatorJS (nhân PCSX ReARMed).
  3. Lưu nhanh: bấm Lưu nhanh bất cứ lúc nào để chụp trạng thái game; Nạp nhanh để quay lại đúng chỗ đó. Muốn giữ save lâu dài thì bấm Tải file save để lưu file .state về máy.
  4. Cheat: thêm mã GameShark trước hoặc trong lúc chơi, bật mã rồi bấm Áp dụng mã.
  5. Phím: dùng bàn phím như tay cầm PS1 (mũi tên + X/Z…). Bấm vào màn hình game rồi chỉnh phím trong nút ⚙️ Cài đặt của trình giả lập.

⚖️ Lưu ý bản quyền

Trang này không kèm game hay BIOS. Bạn cần tự dump đĩa game và BIOS từ máy PS1 của mình. Chỉ dùng cho game bạn sở hữu hợp pháp.
